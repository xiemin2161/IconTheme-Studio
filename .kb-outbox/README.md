# .kb-outbox —— 知识交接箱

**任何 AI（Codex / DSH / Cursor / Claude）都可以往这里丢东西。**

## 怎么用
- 一个发现一个文件，文件名：`YYYY-MM-DD-HHMM-<编辑器>-<简短主题>.md`
- 只写内容，**不整理、不分类、不建索引**——整理是 Codex 的活
- 写完就走，不用管后续

## 写什么
- 踩过的坑、绕过的弯路
- 做过的技术决策及其原因
- 发现的约束、不能动的部分
- 可复用的工具用法、命令、配置
